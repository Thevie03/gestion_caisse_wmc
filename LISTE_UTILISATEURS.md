## 🔄 Comment régénérer la liste

Pour générer une nouvelle liste à jour, exécutez la commande suivante dans le terminal :

```bash
php liste_users.php
```

Un nouveau fichier `LISTE_UTILISATEURS_YYYY-MM-DD_HH-MM-SS.txt` sera créé avec toutes les informations détaillées.

## 📝 Informations incluses dans le fichier généré

Pour chaque utilisateur :

-   ID
-   Nom complet
-   Email
-   Téléphone
-   Rôle (Admin, Employé)
-   Statut (Propriétaire de boutique, Employé, Administrateur)
-   Boutique associée
-   Statut actif/inactif
-   Abonnement (type, dates, montant, statut)
-   Dernière connexion
-   Date de création

## 🏪 Groupement par boutique

Le fichier inclut également une section qui groupe les utilisateurs par boutique, montrant :

-   Le propriétaire de chaque boutique
-   Tous les employés de chaque boutique
